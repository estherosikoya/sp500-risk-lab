# S&P 500 Risk Lab

Type an S&P 500 ticker and see how risky it has been, how reliable the risk models are, and how it moves with the market.

**The question:** How risky is an S&P 500 stock, how reliable are common risk models for it, and how does it move with the market?

**Not included:** Price prediction and buy/sell advice. This is an educational tool.

**Success looks like:** Volatility models compared against a simple baseline using walk-forward testing, and a live app that works for any S&P 500 ticker.
